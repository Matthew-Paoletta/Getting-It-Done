Privacy Policy, Permissions Justifications, and Data Usage Disclosures

📋 Privacy Policy

Last Updated: March 21, 2026

Effective Date: March 21, 2026

WebReg2Cal is designed to respect your privacy. This extension does not maliciously collect, store, or share your personal data.

  • Data Extraction: When you provide your Webreg schedule (either by uploading a screenshot or pasting text), the extension processes this data to extract your class information.
  • Third-Party OCR Service: If you use the screenshot method, the image is sent to a secure, third-party Optical Character Recognition (OCR) API (api.ocr.space) exclusively to extract text. The image is not saved or used for any other purpose.
  • Google Calendar Integration: If you choose to directly sync your schedule to Google Calendar, the extension requests OAuth2 authorization using the `calendar.events` scope. This permission is used strictly to create new events (your classes and week markers) on your personal Google Calendar. WebReg2Cal never reads, deletes, or modifies any existing calendar events, nor does it send your calendar data to our own servers.
  • Local Processing: Besides the initial OCR step and the direct calendar sync, all parsing and generation of `.ics` files happens locally within your browser.
  • Uninstalling: You can revoke Google Calendar access from your Google Account settings, and uninstalling the extension clears any local data managed by it.

🔐 Permissions Justifications

1. identity & OAuth2 Justification

The identity permission and the Google Calendar OAuth2 scope (https://www.googleapis.com/auth/calendar.events) are only utilized when the user clicks the "Add to Google Calendar" button. This enables secure login via Google and allows the extension to automatically generate schedule events in the user's primary calendar. No personal identity data (such as emails or profile pictures) is collected by the developer.

2. Host Permissions (API endpoints)

The extension requires access to exactly three external endpoints:

  • https://api.ocr.space/* — Used to send the user's schedule screenshot for text extraction.
  • https://www.googleapis.com/* and https://accounts.google.com/* — Used exclusively for the Google OAuth authorization flow and the Calendar API event creation.

3. ActiveTab / Storage (Historical)

While previous versions used activeTab and storage, version 1.5.0 and beyond relies on manual image upload or copy-pasting text, meaning the extension only processes user-provided inputs within its popup environment.

4. Remote code usage

No. We do not execute remote code. All JavaScript logic to parse rules and format schedules is bundled directly into the extension package.

📊 Data Usage Disclosures

Data collected & processed:

  • Schedule Information: Class times, locations, course codes, and instructor names provided via screenshot or text paste.
  • Authentication Tokens: Temporary OAuth tokens granted securely by Google (held entirely in the browser memory cache) to facilitate calendar integration.

Data NOT collected:

  • Any personally identifiable information (Name, Student ID, GPA, Phone numbers)
  • Health or Financial information
  • Personal communications
  • Location data or Web browsing history

Certifications:
